This repo is a personal blog focused on data science and legal research, built with Hugo. It features a range of topics, including AI in legal research, Julia programming, and GIS analysis in the energy sector.

## Key Components
- **Hugo**: This is a static site generator, using the Anubis theme for styling.
- **Multi-language support**: Translations available in several languages, including German and Chinese.
- **Interactive elements**: Google Analytics and Disqus comments are integrated, plus syntax-highlighted code blocks with a copy-to-clipboard feature.

## How to Run It
1. Ensure you have Hugo and Git installed.
2. Clone the repo:

    ```bash
    git clone https://github.com/justin-napolitano/another-hugo-blog.git
    cd another-hugo-blog
    ```

3. Run it locally:

    ```bash
    hugo server -D
    ```

Access it via `http://localhost:1313`.

## Important Note
When finished, build the production version with:

```bash
hugo
```

This creates the output in the `public` directory.
